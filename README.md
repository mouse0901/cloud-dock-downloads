## 你的网盘，一个顺手的工作区

工作资料、分享文件、正在下载的任务，不必在多个窗口间反复寻找。云屿把常用操作整理在一起，让浏览、整理和传输更清楚。

### 📁 浏览与整理

在列表和网格之间切换；通过搜索、多标签页和常用文件操作，找到需要的内容并整理目录。文件夹与常见文件类型使用不同图标，浏览时更容易分辨。

### ⇅ 上传与下载

在传输中心查看上传、下载和任务状态。对适用的任务可以暂停、继续或重试；任务记录和通知帮助你了解进度与需要处理的事项。

### 🔗 打开分享链接

在云屿中打开百度网盘或夸克网盘分享，先查看内容，再选择需要的文件与下载位置。链接库可以保存和再次打开使用过的分享。

### ↻ 同步与多账号

按需设置文件或文件夹同步方向，查看同步事项；也可以管理和切换个人网盘账号。首次使用同步时，建议先用小范围目录核对方向和位置。

### 📄 在线预览

使用大阅读区查看 PDF、文本、代码、图片、音频和视频，支持全屏阅读。可用线路按需读取；文件格式、编码及网盘线路能力会影响实际效果。

### ◐ 更贴近桌面的体验

支持浅色与深色主题、系统托盘、任务通知和常用界面设置。关闭窗口后是否保留托盘运行，可以在软件设置中调整。

> **使用范围：** 网盘可用功能、文件操作和传输速度受平台、账号权益、文件及网络环境影响；测试版功能请以实际使用情况为准。

## 下载与安装

**当前公开版本：1.2.1-beta.5 测试版**

1. 打开 [1.2.1-beta.5 版本页面](https://github.com/mouse0901/cloud-dock-downloads/releases/tag/v1.2.1-beta.5)。
2. 在 **Assets** 中下载 `CloudDock-1.2.1-beta.5-Setup-x64.exe`。
3. 运行安装程序，根据向导选择程序目录和独立的数据目录。软件使用 Windows 10 / 11 64 位环境，依赖 .NET Framework 4.8 和 Microsoft WebView2。

> 安装程序目前尚未取得 Windows 代码签名，系统可能提示“未知发布者”。请从本仓库的版本页面下载，并按下方方法核对文件。

<details>
<summary><strong>如何核对安装包 SHA-256？</strong></summary>

在 PowerShell 中运行下面的命令，把引号里的路径换成你下载的安装包路径：

```powershell
Get-FileHash -Algorithm SHA256 "安装包的完整路径"
```

```text
bf72032c5573868994d50425706ff16cccdbcca2d6f2e7489d9737ddd2c38fdb
```

校验值也可在对应版本的发布说明中查看。以后下载其他版本，请以对应版本的校验信息为准。

</details>

### 从旧版升级

**先完成或暂停正在进行的传输与同步，并从托盘退出旧版。**

- **已有安装版：** 在安装向导中确认原来的数据目录。旧安装目录下的 `installed-data.txt` 可用于查看记录的数据位置；若安装器提示旧程序文件冲突，请选择新的程序安装目录，再核对数据目录。
- **已有便携版：** 在向导的“从便携版导入”页面选择旧程序所在目录，并使用新的独立数据目录。导入会保留旧目录；同步规则导入后先暂停，核对账号和位置后再启用。
- **数据与下载：** 程序目录和数据目录请分开；原有下载与同步文件不会因导入被移动。重要文件建议自行备份。

## 版本更新

仍使用旧更新地址的版本，**需要先手动安装一次新版**；已使用公开下载仓库更新源的版本，可以直接检查更新。安装后可在软件的 **设置 → 关于与更新** 中检查、下载更新，并自行选择安装时间。更新信息会经过签名校验，下载的安装包也会核对大小和 SHA-256。

- **正式版通道**：默认选择；当前正式版为 1.2.0。
- **测试版通道**：希望接收后续测试版时，可在更新设置中主动选择。

遇到网络或 GitHub 连接问题时，可以检查软件中的更新网络设置，再手动重试。

## 常见问题

<details>
<summary><strong>在哪里登录网盘账号？</strong></summary>

打开软件左下角的“我的账号”，选择对应网盘并按提示连接。请使用自己的网盘账号。

</details>

<details>
<summary><strong>关闭窗口后，任务还会继续吗？</strong></summary>

取决于托盘设置。云屿可以在关闭窗口后留在系统托盘；要结束后台，请从托盘菜单或软件设置中退出。退出前请先处理正在进行的任务。

</details>

<details>
<summary><strong>为什么软件提示检查更新失败？</strong></summary>

请先检查网络与软件里的更新网络设置，然后手动重试。检查失败不代表已经是最新版本；你也可以直接查看 [GitHub 版本页面](https://github.com/mouse0901/cloud-dock-downloads/releases)。

</details>

<details>
<summary><strong>更新或卸载会删除网盘文件吗？</strong></summary>

安装与卸载针对本机程序，不会主动删除网盘文件。程序、数据和下载位置请按向导分开并核对；重要资料建议自行备份。

</details>

## 关于云屿与这个仓库

云屿连接你自己的网盘账号，登录会话由当前 Windows 用户加密并保存在本机；使用网盘功能时，软件会与相应网盘服务通信。

此公开仓库用于提供安装包、首页介绍和更新所需文件；云屿项目源码保存在私有仓库。请勿在公开页面提交网盘账号、Cookie、分享链接提取码或个人文件。
