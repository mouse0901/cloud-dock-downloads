## 在云屿，你可以

- **浏览文件**：用列表或网格查看文件，搜索、切换标签页，整理常用资料。
- **管理传输**：集中查看上传与下载任务，按任务状态处理暂停、继续或重试。
- **使用分享链接**：在软件内打开百度或夸克分享，查看内容后再选择所需文件。
- **管理同步和账号**：按需配置同步规则，切换个人网盘账号，查看任务通知。

网盘功能、速度和可用操作会受平台、账号权益及网络环境影响，请以实际使用为准。

## 下载与安装

目前公开的是 **1.1.4-beta.1 测试版**，适用于 Windows 10 及以上版本的 64 位系统。在[版本页面](https://github.com/mouse0901/cloud-dock-downloads/releases/tag/v1.1.4-beta.1)的 **Assets** 中下载 `CloudDock-1.1.4-beta.1-Setup-x64.exe`，按安装向导操作。

已有旧版的用户，请先让传输与同步任务安全结束，并从托盘退出云屿。安装版按向导保留原数据位置；如果提示旧程序文件需要新的安装目录，请选择新目录。旧便携版可在安装向导中选择导入，原便携版数据会保留。

> 安装程序目前尚未取得 Windows 代码签名，系统可能显示“未知发布者”。请从本仓库的 Release 页面下载安装包。

## 软件更新

安装本版后，可以在软件的 **设置 → 关于与更新** 中检查新版本。默认接收正式版更新；如需接收测试版，请在更新设置中选择测试版通道。正式版通道目前暂无可用的新版本。

旧版本使用的更新地址无法自动切换，需先手动安装一次本版。更新包会进行签名和文件完整性校验。
